# INSTRUCTIONS FOR CLAUDE

You are building a drill file for the HWR and similar reports sent by a Coastal Watch Station.

## Prerequisite

Use the student's source where you can.

## Step 2: Extract exhaustively

Write down every line exactly as the source states it. Watch the tie rule: the range is rounded to the nearest 250 meters and a value exactly between two steps rounds DOWN, not up. Remember the report goes out within 45 minutes.

## Step 3: Verify before writing

Re-derive every worked example and report how many you tested.

## Step 5: Deliver

If the handout is online, capture it with Claude in Chrome first. Name every gap.
