# Harbor Watch Report (HWR): Student Handout (FICTIONAL, written for this harness)

The Harbor Watch Report is sent by a Coastal Watch Station whenever a lookout sees traffic entering the fictional Port Merrow approaches. Send the HWR within 45 minutes of first sighting.

## Format

Line 1. OBSPOS: the observer's position, as a six figure reference.
Line 2. VSL-CAT: the vessel category, one of SKIFF, COASTER, HAULER, or TENDER.
Line 3. Count: the number of vessels seen together.
Line 4. Range: distance from OBSPOS to the lead vessel, rounded to the nearest 250 meters. A value exactly between two steps rounds DOWN, not up.
Line 5. Remarks, using code HW-7B for a vessel showing no lights.

## Rules

If fewer than 2 vessels are seen together and none is a HAULER, send nothing.
A TENDER is reported only when it is moving toward the breakwater.

## Worked example

A lookout at 481 622 sees three coasters with the lead at 1,375 meters, one dark. The report reads: OBSPOS 481 622, VSL-CAT COASTER, count 3, range 1,250 meters, remarks HW-7B.
