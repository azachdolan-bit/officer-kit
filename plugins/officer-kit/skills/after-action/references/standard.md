# Standard: the after action report

No Marine Corps order prescribes a single AAR format for units. MCO 1553.3C (Unit Training Management, 9 Aug 2023) requires that training be evaluated and that results feed the next plan, and MCTIMS carries the record; the format is the unit's SOP. The shape below is the common one, and the override file replaces it with the unit's.

## What an AAR must do (from MCO 1553.3C's intent and common SOPs)
- State what was planned, so the reader can see the difference.
- State what happened as facts, by phase, with times and numbers.
- Separate what to sustain from what to improve.
- Assign each improvement an owner and a date, or it will not happen.
- Be short enough to be read by the next OIC of the same event.

## What an observation must contain
A time or phase, a fact, a number where one exists, and the difference from the plan. Not a judgment, not a name.

## Where it goes
The S-3 or the training officer; MCTIMS where the unit records AARs there; the unit's shared AAR folder. The override file says which.
