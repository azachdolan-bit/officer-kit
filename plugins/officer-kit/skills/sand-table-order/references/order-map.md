# From the plan to the paragraphs

The order format is the user's own first: their school or unit skeleton and drafting playbook from their Reference or planning folder. Where they have none, the platoon format is MCRP 3-10A.3 Appendix J (`../../order-analysis/references/order-format.md` in this plugin). This map says which part of the export feeds which paragraph; it adds nothing the export does not hold.

| Paragraph | From the export |
|---|---|
| Orientation | aoi corners; terrain (key terrain, observation, cover, obstacles, weather) |
| 1.A Enemy: composition, disposition, strength; capabilities and limitations; EMLCOA | enemy (size, unit, equipment, last known location, activity, time, how sure; capable; limited); terrain avenues; emlcoa (mission, current, contact, avenue used, objective); cgcv |
| 1.B Friendly: higher mission and intent; adjacent; supporting | mission (higher); troops (adjacent, mortars, fires, organic) |
| 1.C Attachments and detachments | dist attach (defense) or oto (offense, machine guns) |
| 2 Mission | mission (statement); specified and implied |
| 3.A Commander's intent | cgcv (exploitation); parts (the last part's ends with as the end state); mission purpose |
| 3.B.1 Scheme of maneuver | defense: type, ea, dist, orient, occ, tcm, sec, obst, then parts; offense: oform, oto, otcm, oseq, then parts; the major TCMs from the map with their grids, one per line (see How the paragraphs read); the direct fire plan from the reader's table (each position's LLL and RLL, each gun's FPL or PDF, in grid azimuth with magnetic and mils beside it where the format wants them; the TRPs inside each sector with range and azimuth); the annexes named: the fire plan sketch PNG and one range card PNG per gun, exported from the page |
| 3.B.2 Fire support plan | fsp (EFST, targets with trigger, location, observer, delivery; FPF); troops fires |
| 3.C Tasks | tasks (t1 to t3, the MG statement in its four elements: relationship, condition, task, purpose); each object's task and purpose props; the MG task carries the FPL or PDF azimuth from the direct fire plan |
| 3.D Coordinating instructions | coord (timeline, engagement criteria, other); oseq signals (offense); time (one third line) |
| 4 Administration and logistics | admin (CASEVAC, CCP, CASEVAC route with legs, EPW, resupply) |
| 5 Command and signal | admin c2; oseq signals (offense); anything else is NOT IN THE PLAN |

Annexes ride beside the order as files the page exports, named in 3.B.1: the platoon fire plan sketch (Plan, Fire plan sketch (PNG); B3M0830XQ-DM Annex D) and a standard range card per machine gun (Objects, Position and sector, Range card (PNG); MCTP 3-01C pp. 4-23 to 4-28). Grazing fire, dead space along the FPL and inside the sector, and the orientation diagram are on the cards; the plan file does not carry them, so the order quotes none of those figures from anywhere else.

Two lists close the order: NOT IN THE PLAN (every paragraph element the export did not hold, named) and Warnings carried (every warn check from the brief, verbatim).

## How the paragraphs read

From the corrections of a planner who briefs these orders (FEX III, Oct 2026). The order is lean: the length of the user's own official orders.

- **Orientation.** Box, trace, familiarize in a short paragraph.
- **1.a Enemy.** (1) Composition, disposition, strength: one sentence on who, where and when seen, one line of equipment, one line on how they operate. (2) Capabilities and limitations: one line per DRAW-D letter, "D: capability. Limited by ...". (3) EMLCOA: one tasking statement with a tactical task, "[enemy unit], [when], [task] [where] IOT [purpose]"; then "CA:" one line of current activity and "AOC:" one or two lines of actions on contact.
- **1.b Friendly.** Higher's mission pasted verbatim from the base order's mission paragraph. Adjacent: each unit's tasking pasted verbatim from the base order's tasks, with its BP grid. Supporting: the fires with their POF.
- **3.b(1) TCMs.** One per line, the TCM, then beneath it the next: LD, ORP, SRP, BP, then the trigger lines, TRP, FPF and CCP. No squad or gun positions; they are in the direct fire table.
- **Movement.** Wavetops, one line per leg: "LD to ORP: [mag az] mag, [distance] m. FOM [formation]. OOM [order]." A direct azimuth for each leg; a route uses as few checkpoints as possible. No leg tables.
- **Parts.** The planner's parts by name, each with BW, CE, EW, CS and its movement lines; walk the dog only where the user's format wants it, marked as not part of the written order.
- **3.b(2) Fire support plan.** Each EFST reads Task, Purpose, Method, Effects. Task, Purpose and Effects pasted verbatim from the base order; the Method is the planner's TTLODAC for each target: T (task), T (trigger), L, O, D, A, C. C is always filled with the net (for example "60s COF net" or "81s COF net"). An element the plan lacks is flagged for the planner, never invented.
- **3.c Tasks.** Under each part, every element on its own line: "[unit]. [T/O]. Upon [condition], [tactical task] [where] IOT [purpose]." A defense block task reads "Upon [trigger], block [portion] of the EA IOT [the platoon's mission purpose]." BPT statements only where the planner gave them.
