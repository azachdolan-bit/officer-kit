# Standard: MCO 5040.6K (Inspector General of the Marine Corps Inspections Program, 1 May 2026) and the IGMC functional area checklists

The IGMC Inspections Division publishes functional area checklists (CoRE, CoRE plus, and non CoRE) on its site; each checklist item asks a question and cites the reference it comes from. Programs commonly inspected at the company and battalion level include military awards (1650), career planning (1040), leave and liberty (1050), the safety management system (5100.29), SAPR (1752.5), and consumer level supply (4400.201).

What an inspector expects: an appointment letter for the program officer; the governing order on hand; a binder or folder in checklist order with the evidence for each item; a self assessment done before the inspection; discrepancies from the last inspection closed with evidence.

The tool reads the checklist from `Reference/Checklists/<program>.md`, which the user saves from the IGMC site. Checklist versions change; the file carries its date.
