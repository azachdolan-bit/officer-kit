# Inspection prep intake

1. Which program, which inspection, when, and who is responsible (billet)? Is the current IGMC checklist saved in Reference/Checklists? (If not, get it from the IGMC Inspections Division site and save it with its date.)
2. For each checklist item: what document answers it, and where is it now? If nothing answers it, what would?
3. What did the last inspection find, and is each finding closed with evidence?
4. Who owns each fix, by billet, and by when, given the inspection date?
5. How does the command want the binder built (tabs, order, digital or paper)?
