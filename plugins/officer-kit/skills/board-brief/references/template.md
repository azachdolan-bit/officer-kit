# Board briefing sheet template

One page. The briefer reads top to bottom. Field names are fixed so the checker can find them; values come from the package. A value the user could not supply prints as `[ ]`.

```
# Board brief: <Grade Name>, <MOS>, <Unit>
Board: <meritorious promotion to Cpl | Group NCO of the Quarter, 1st Qtr FY26>   Clock: <N> minutes

Billet: <billet, since month year; above grade if so>
Additional duties: <list, or none>
Derogatory material: <none | see package>
TIS / TIG: <years months> / <years months>
Billets held in grade: <billet, dates; billet, dates>

PME: <Leading Marines DEP, completed month year; Corporals Course DEP, month year>
MCI / MarineNet: <count; two or three by name>
Reading list: <count; titles>
Off duty education: <credits toward degree, or none>

PFT: <score, class, month year>       CFT: <score, class, month year>
Rifle: <score, class>                  Pistol: <score, class>
Swim: <level>                          MCMAP: <belt>
Height / weight: <inches / pounds, within standards>

Annual training: <complete | items outstanding>
Awards: <list, or none>
Deployments: <unit, dates, billet | not yet had the opportunity>
Community service: <hours by organization>

## So what
1. <fact with a number, and what it did for the unit>
2. <fact with a number, and what it did for the unit>
3. <fact with a number, and what it did for the unit>

Questions the board may ask: <two or three, with the answer in one line each>
```

## Reading order

Header and clock, then the block in order. The briefer does not read the field names aloud; the sheet's order is the spoken order. The so what lines are read last and slowly. The questions block is not read; it is the briefer's own crib.

## Fields the checker requires

Board, Clock, Billet, Additional duties, Derogatory material, TIS / TIG, PME, MCI / MarineNet, Reading list, Off duty education, PFT, CFT, Rifle, Pistol, Swim, MCMAP, Height / weight, Annual training, Awards, Deployments, Community service, and three numbered lines under `## So what`.
